Make a casino habit tracker mobile app.
Spin the jackpot slot machine for the maybe effect. When a user marks a habit as complete they get one spin on the slot machine
When creating a habit you want to track - set goals for yourself and rewards. For example: when you've done your habit for x days or done the habit y times you've earned your reward.
The most important feature is the spinning slot machine. When you do your habit you get one free spin. The slot machine might not give you anything or you could earn a small reward or even a jackpot. The "maybe" factor is important here. Your habit will be far more addicting if you aren't always rewarded for doing it. There should be exciting visuals and animations when the slot machine is running. There should be exciting animations while the slot machine is running to build up anticipation in the user. There also needs to be away to see how many days you've kept up your habit streak. It should be a calendar view and it should have some fire effect and colors if you've maintained the habit for more than 10 days

There are many different types of rewards:

- a small reward for completing the habit today (luck based, and can be multiple depending on the slot)
- a big reward for doing the habit N times
- a big reward for keeping the habit for N days

Pixel art style. The theme of the app is making a deal with the Devil

I want it to be mobile app built with the Dioxus framework. I am a novice rust developer
